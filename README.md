# JavaScript_mini_project-SimonSaysGame-
## 🎮 How to Play

Simon Says Game is a memory-based game where you need to remember and repeat the sequence of colors shown by the game.

### 🕹️ Game Instructions

1. Press any key to **start the game**.
2. The game will flash one colored button.
3. Click the **same colored button**.
4. In the next level, the game will flash another button.
5. Remember the previous sequence and click the buttons in the **correct order**.
6. Continue following the sequence as the level increases.
7. If you click the wrong button, the game is **over**.
8. Your score is based on the highest level you successfully complete.

### 🏆 Objective

Remember the longest possible sequence and achieve the **highest score**!

### 🔄 Restart

After Game Over, press any key to start a new game.
